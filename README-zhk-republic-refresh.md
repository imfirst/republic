# ЖК «Репаблик» — обновление страницы ГИП

## Что изменено

- Переработан универсальный шаблон `qreator_zhk.html`: hero больше не обещает, что каждый раздел уже согласуется автоматически; убраны необоснованные гарантии согласования и повторяющаяся FAQ-разметка.
- Заменён общий блок FAQ на вопросы о составе проекта, исходных данных, согласовании и границах услуги (ГИП выполняет проектирование, не монтаж).
- Добавлены универсальные стили для подробного инженерного контента в `[[*content]]`: карточки фактов, таблицы, примечания, галерея и адаптивная мобильная сетка.
- Подготовлен самостоятельный контент `ЖК_Репаблик.html` с описанием инженерных систем по изученным ТУ.
- Подготовлены SEO-настройки и перечень фото для загрузки в MODX: `Настройки_страницы_ЖК_Репаблик.md`, `republic-assets-manifest.md`.

## Границы достоверности

Параметры взяты из файла «Технические условия ЖК Репаблик», размещённого в исходном репозитории, и сопоставлены с официальным сайтом квартала. ТУ не являются паспортом каждой квартиры; в частности, температурные зоны 7/12 и 5/10 °C относятся к изученному экземпляру документа. Для любого нового проекта значения сверяются с корпусом, секцией, этажом, узлом подключения и актуальными требованиями УК.

## Перед публикацией

1. Скопировать фото по таблице из `republic-assets-manifest.md` в `/images/lp01/republic/`.
2. Не загружать фотографии с открытым номером квартиры и не публиковать индивидуальные рабочие планы.
3. В MODX установить шаблон `qreator_zhk.html`, заполнить поля `ЖК`, `adress`, `zastroy` и метаданные из файла настроек.
4. Вставить `ЖК_Репаблик.html` в поле `content`.
5. Перед публикацией проверить страницу на реальном ресурсе: вывод HTML внутри `[[*content]]`, загрузку изображений, мобильную сетку, калькулятор, кнопки мессенджеров и canonical URL.
